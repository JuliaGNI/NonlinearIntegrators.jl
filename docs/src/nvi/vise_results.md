# VISE Results

`VISE` (Variational Integrator with Symbolic Expression) takes a user-supplied `Symbolics.jl` expression as the ansatz for the continuous trajectory, instead of a trained neural network. The expression parameters are fitted by the nonlinear solver at each time step. This makes it exact for problems whose solution lies in the chosen function class.

The parameter scan covers the quadrature order `R`, the timestep `h`, and the network weight precision `dtype`. Three test problems are included: Harmonic Oscillator, Perturbed Pendulum, and Hénon-Heiles Potential.

## Running the Parameter Scan

The parameter grid (`h`, `R`, and `dtype`) is configured at the top of `parallel_run.sh`:

```bash
# In parallel_run.sh:
INTEGRATOR="vise"

bash parallel_run.sh
```

After all jobs complete:

```bash
julia --project=scripts scripts/result_summary_vise.jl
```
